# Reviewer focus

Please prioritize correctness over feature count. Look for:

- false culprit attribution;
- hidden correlation between nominally independent WinDbg fields;
- malformed dump boundary handling;
- symbol-quality misclassification;
- PowerShell/cmd quoting and encoding failures;
- Autofix policy bypass through command or verification fields;
- UI races while toggling optional AI;
- misleading language that turns a hypothesis into a fact.
